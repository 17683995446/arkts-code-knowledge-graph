# ArkTS 代码知识图谱系统 - 可视化网站 PRD

## 1. 概念与愿景

### 项目背景
ArkTS 代码知识图谱系统是一个企业级的代码分析平台，支持千万级代码的解析、关系分析和语义搜索。为了让开发者更直观地理解系统架构和代码流程，需要创建一个专业的可视化网站。

### 核心价值
- **清晰展示**：通过架构图、流程图、时序图等方式，直观展示系统设计
- **实时更新**：每次代码文件修改后，自动更新可视化内容
- **交互体验**：提供丰富的交互功能，支持缩放、导航、搜索等
- **技术展示**：展示系统使用的核心技术和优化策略

### 目标用户
- 系统开发者：理解系统架构和模块关系
- 技术管理者：评估系统设计和技术选型
- 新成员：学习系统架构和代码规范

## 2. 设计语言

### 美学方向
**科技感 + 数据可视化风格**
- 采用深色主题，营造专业的技术氛围
- 使用霓虹色彩的渐变，突出重点元素
- 流动的动画效果，增强动态感知
- 网格背景，模拟技术蓝图

### 字体系统
- 标题：Orbitron, Rajdhani
- 正文：Source Sans Pro, Noto Sans SC
- 代码：JetBrains Mono, Fira Code

### 动效设计
- 入场动画：元素从下方淡入，配合延迟效果
- 流程动画：箭头流动效果，表示数据流向
- 悬停效果：元素发光、放大、颜色变化

## 3. 页面结构

### 3.1 概览页面（Dashboard）
- 系统总体架构图
- 核心指标统计
- 最近更新日志

### 3.2 架构图页面（Architecture）
- 分层架构图（Infrastructure → Core → Services → CLI）
- 模块依赖关系图
- 数据流架构图

### 3.3 流程图页面（Flow）
- 完整解析流程时序图
- 符号表构建流程
- 知识图谱构建流程

### 3.4 模块详情页面（Modules）
- 文件目录结构树
- 模块依赖关系
- 模块间的调用关系

### 3.5 技术栈页面（Tech Stack）
- 使用的技术栈展示
- 第三方库依赖图
- 性能优化策略

## 4. 核心功能

### 4.1 架构图展示
- 多层架构图：可点击展开/折叠
- 实时更新：代码修改后自动刷新
- 缩放控制：鼠标滚轮缩放，支持全屏模式
- 信息提示：悬停显示详细信息

### 4.2 流程图展示
- SVG 绘制：使用 SVG 实现高清流程图
- 动画效果：箭头流动、节点发光
- 交互操作：点击节点查看详情

### 4.3 时序图展示
- 参与者展示：展示系统各组件
- 消息流动：动画展示调用过程
- 时间标注：标注每步耗时

### 4.4 文件树展示
- 树形结构：清晰展示目录层级
- 文件类型图标：区分 TS/JS/JSON 等
- 快速预览：点击查看文件内容

## 5. 技术方案

### 前端框架
- React 18 + TypeScript
- Vite - 快速构建工具
- Tailwind CSS - 原子化 CSS 框架

### 可视化库
- D3.js - 数据可视化
- Mermaid.js - 流程图/时序图绘制

### 自动化更新
- Node.js 脚本 - 定时解析代码生成数据
- Git Hooks - 提交时自动更新
- 文件系统监听 - 文件变更时触发更新
